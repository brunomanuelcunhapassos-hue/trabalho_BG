O que são os métodos contracetivos de barreira?

Os métodos contracetivos de barreira são meios utilizados para prevenir a gravidez, impedindo fisicamente que os espermatozoides cheguem ao óvulo.

Alguns destes métodos também ajudam a proteger contra infeções sexualmente transmissíveis (IST).

A prevenção é o primeiro passo para uma sexualidade responsável.
